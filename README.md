# Прогноз повітряних тривог в Україні

Прогноз ймовірності повітряної тривоги в **районах** України на 1, 3 і 6 годин уперед. Модель враховує, куди загроза може полетіти далі від фронту: тривоги в прифронтових районах — сигнал для тилових.

Головна вимога — **жодного витоку даних**: модель використовує лише те, що було відомо на момент прогнозу, а оцінюється на найсвіжішому доступному періоді.

## Дані

- **Тривоги:** офіційний датасет [Vadimkin/ukrainian-air-raid-sirens-dataset](https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset) (ліцензія MIT), з 15.03.2022. З кінця 2025 р. тривоги оголошують переважно по районах. Датасет перестав оновлюватися 07.09.2026, тому MVP тестуємо на 02.08–29.08.2026, а свіжі дані додамо з каналу @air_alert_ua (рішення D-7).
- **Межі й коди районів:** [OCHA COD-AB Ukraine](https://data.humdata.org/dataset/cod-ab-ukr). Малюємо лише власні полігони, без сторонніх базових карт: Крим і Севастополь — у складі України.
- **Мова:** лише україномовні джерела (рішення D-11).

Статус і перевірка кожного джерела — у додатку A в [JOB_STORIES.md](JOB_STORIES.md).

## Захист від витоку даних

Повний перелік критеріїв — JS-5 в [JOB_STORIES.md](JOB_STORIES.md). Коротко:

- ознаки рахуються лише з даних, відомих до моменту прогнозу T; тривогу, що триває в T, обрізаємо по T;
- вибірки train → validation → test ідуть за часом, між ними — проміжок у h годин;
- статистики й нормалізацію рахуємо лише на train, test запускаємо один раз наприкінці;
- автотест (крок 4) перевіряє, що видалення всіх даних після T не змінює ознак на момент T.

## Запуск

Потрібен Python 3.11 або новіший (перевірено на 3.13).

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -e . --no-deps
.venv/bin/python -m pytest
```

Ключі Telegram API знадобляться лише для кроків після MVP: скопіюйте `.env.example` у `.env` і заповніть. Файл `.env` не потрапляє в git.

## Технології

- Python 3.13, Polars, DuckDB, Parquet — обробка й зберігання даних.
- scikit-learn: `HistGradientBoostingClassifier` — гістограмний градієнтний бустинг. LightGBM не використовуємо: на macOS він потребує системної бібліотеки `libomp`, тобто ручного кроку встановлення.
- GeoPandas — межі районів, сусідство; matplotlib — графіки у WebP без втрат.
